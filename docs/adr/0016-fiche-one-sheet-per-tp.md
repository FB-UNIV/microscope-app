# A Fiche is one sheet per TP: each Échantillon's Vue principale with its Grossissement and Échelle

**Status:** supersedes the one-page-per-Échantillon layout of [ADR 0010](0010-fiche-generated-artifact-cap-dropped.md); its rule that a Fiche is generated as a file before anything is printed still stands. Its own "as few A4 pages as fit" layout is in turn superseded by [ADR 0019](0019-fiche-three-vues-per-page.md) (three Vues per page, one per row); what a Fiche shows still stands, except that a Vue principale is no longer printed "rendered with its Treatments": [ADR 0022](0022-fiche-prints-the-original-with-its-echelle.md) prints its original photo with only its Échelle.

ADR 0010 left open what a Fiche shows beyond the Échantillon name and its Vue principale. Decided: a Fiche covers one TP. For each Échantillon of that TP it shows the name, the Vue principale rendered with its Treatments, the Grossissement, and the Échelle scale bar, laid out on as few A4 pages as fit. Nothing else is printed: no Department or date header, no Phase analysis or Dureté Vickers results, no lines for handwriting. Considered one page per Échantillon, ADR 0010's original framing: simpler to lay out, but a TP with 6–8 Échantillons would print 6–8 mostly empty pages, where the legacy app already grouped up to 3 views per page.

**Consequences:** The Fiche renderer takes a TP, not an Échantillon. The Grossissement printed for a Vue comes from the Calibration in its sidecar (ADR 0015), and every calibrated Vue already carries its Échelle (ADR 0017), so an uncalibrated Vue principale has neither to print; how the sheet shows that, and an Échantillon with no Vue principale yet, is left to the Fiche implementation. Lab results stay on screen only: printing them would first need them saved with the Vue, and Measurement is ephemeral by design.
